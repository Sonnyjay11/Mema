# Coffee Date Invitation — Mimz ♡

A minimalist sky-blue interactive date invitation for Mimz, from Jay.

## Files

- `index.html` — website structure
- `style.css` — minimalist sky-blue design
- `script.js` — calendar/time picker, Yes screen, playful No button, and optional song link

## Add "Love Is" by The Ridleys

Because the song itself is copyrighted, this project does not include an audio file.

To make the song button open your preferred official/streaming page:

1. Open `script.js`
2. Find:
   `const SONG_URL = "";`
3. Paste the song's Spotify/YouTube URL between the quotes.
4. Save and upload the updated file to GitHub.

## GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your website URL.

Your invitation will be ready to share.
